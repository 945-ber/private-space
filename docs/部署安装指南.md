# 树洞 · 零基础部署安装指南

> 目标读者：**完全没接触过这套代码的程序员（或想自己搭一个的人）**。
> 只要按顺序做，每一步都有「怎么验证做对了」，做完就能得到一个**公网上别人也能访问**的网站。
>
> 本文以 **Windows 系统** 为主（附 Linux/macOS 差异说明），全程不用写一行代码。

---

## 一、这套东西是什么技术栈？

| 层 | 技术 | 作用 |
|---|---|---|
| 后端服务 | Node.js + Express | 处理登录、发帖、房间、资料等所有 HTTP 请求 |
| 实时通信 | Socket.IO | 房间/私信的消息实时收发 |
| 数据库 | MongoDB | 存用户、帖子、房间、消息（支持阅后即焚自动删除） |
| 会话 | express-session | 登录状态保持 |
| 密码 | bcryptjs | 密码哈希加密 |
| AI 能力 | 火山方舟（豆包）API | 帖子打标 + 聊天回复建议（**可选**，不配也能用） |
| 前端 | 原生 HTML/CSS/JS | 无需构建，零依赖，浏览器直接打开 |

**架构简图**

```
浏览器（用户）
   │  HTTPS
   ▼
公网隧道（让外网能访问你的本机） ──► Node.js 服务（端口 3000）
                                        │        │
                                        ▼        ▼
                                    Express  Socket.IO
                                        │        │
                                        ▼        ▼
                                   MongoDB（27017）  AI 接口（可选）
```

## 二、环境要求

| 软件 | 版本要求 | 说明 |
|---|---|---|
| Node.js | **≥ 18** | 代码用到内置 fetch、AbortController |
| MongoDB | **≥ 5.0**（推荐 6/7） | 用官方 MongoDB Community Server |
| 系统 | Windows 10/11（本指南）| Linux/macOS 见文末差异说明 |
| 浏览器 | 任意现代浏览器 | 手机、电脑均可 |

> 不需要懂 Node、不需要懂 MongoDB，跟着装就行。

---

## 三、第一步：安装 Node.js

1. 打开官网：<https://nodejs.org/zh-cn> → 下载 **LTS（长期支持版）** 安装包；
2. 双击安装，一路「Next」，**全部用默认选项**（安装路径可改，但要记住）；
3. **验证是否装好**：按 `Win + R` 输入 `cmd` 回车，在黑窗口里输入：

   ```bash
   node -v
   npm -v
   ```

   能打印出版本号（如 `v20.x.x` 和 `10.x.x`）就成功了。

---

## 四、第二步：安装 MongoDB

1. 打开 MongoDB 官方下载页：<https://www.mongodb.com/try/download/community>；
   - Version 选最新稳定版，Platform 选 **Windows**，Package 选 **msi**；
2. 下载后双击安装：
   - 勾选同意协议 → **Custom（自定义）**；
   - 安装路径建议改成 `C:\mongodb`（后面脚本默认找这个路径）；
   - 安装向导里如果出现 **"Install MongoDB Compass"** 的勾选项，可取消（图形界面工具，非必需）；
   - 安装完会自动注册成 Windows 服务并开机自启（本指南依赖这一点）。
3. **创建数据目录**：打开 `C:\mongodb`，新建一个空文件夹，命名为 `data_new`；
4. **验证是否装好**：cmd 里输入：

   ```bash
   mongod --version
   ```

   能打印版本号即成功。

> 💡 如果没自动注册成服务，也可以手动启动：cmd 里运行
> `"C:\mongodb\bin\mongod.exe" --dbpath "C:\mongodb\data_new" --port 27017`，保持窗口开着即可（窗口不能关，关了数据库就停了）。

---

## 五、第三步：获取代码

你会拿到一个压缩包 `private-chat-vX.zip`（X 为版本号）。

1. 把它**解压**到任意目录，例如 `D:\private-chat`；
2. 解压后目录里应有这些关键文件：

```
private-chat/
├── server.js          ← 后端服务器（入口）
├── ai.js              ← AI 版主 + 智能回复
├── ai.config.json     ← AI 接口配置（API Key 填这里）
├── package.json       ← 依赖清单
├── seed-posts.js      ← 初始化脚本（建管理员 + 预置帖子）
├── start-chat.ps1     ← Windows 一键启动脚本（可选）
├── public/            ← 前端页面（浏览器直接访问）
│   ├── index.html     ← 登录/注册页
│   ├── chat.html      ← 主界面（广场/房间/私信/我的）
│   ├── chat.js        ← 前端逻辑
│   ├── style.css      ← 全部样式
│   └── logo.svg       ← 专属 LOGO
└── docs/              ← 文档（本手册 + 产品使用手册）
```

---

## 六、第四步：安装依赖

1. 打开 cmd，进入项目目录：

   ```bash
   cd D:\private-chat
   ```

2. 安装依赖：

   ```bash
   npm install
   ```

   等待下载完成，看到 `added xxx packages` 即成功。

   > 国内网络慢可先执行 `npm config set registry https://registry.npmmirror.com` 换镜像再装。

---

## 七、第五步：配置 AI（可选，不配也能用）

AI 功能（帖子自动打标签、聊天回复建议）依赖一个**豆包/火山方舟**的 API Key。
如果你暂时没有，**跳过这步**——网站其他功能全部正常，只是帖子标签显示「待分类」、聊天里没有 AI 回复按钮。

1. 打开 `ai.config.json`，改成：

   ```json
   {
     "apiKey": "ark-你的_API_Key",
     "model": "doubao-seed-2-1-turbo-260628"
   }
   ```

2. 如何拿 Key：
   - 去 <https://console.volcengine.com/ark> 注册火山引擎账号；
   - 创建 API Key（形如 `ark-xxxx-...`）；
   - **不要把这个 Key 提交到 Git 仓库 / 发给别人**，它等于你账户的钥匙。

3. 模型名可在该文件里改，支持方舟平台任意已开通的豆包/Seed 模型。

> ⚠️ 如果 `ai.config.json` 里留着一个别人分享给你的真实 Key，请务必换成你自己的，或把它删掉。

---

## 八、第六步：初始化数据（可选但推荐）

首次运行前，可以预置一个**管理员账号**和几条**优质话题**，让广场不空荡荡：

```bash
node seed-posts.js
```

看到提示即成功：

```
✅ 管理员账号已创建: admin / admin123
🌱 已预置 6 条优质话题（作者: admin）
```

> ⚠️ 注意：
> - 这个脚本会**清空广场现有帖子**再写入种子数据，只在首次部署时跑一次，之后不要重复运行；
> - 管理员初始密码是 `admin123`，**上线后务必登录 admin 改成自己的密码**。

---

## 九、第七步：启动服务器

```bash
npm start
```

看到如下输出即成功：

```
✅ MongoDB 连接成功
服务已启动: http://localhost:3000
```

**验证**：浏览器打开 `http://localhost:3000`，能出现登录页就成功了。

> 保持这个窗口开着，服务器就在运行中；关掉窗口服务就停了。
> 想后台运行可另开一个终端窗口执行，或用 `start-chat.ps1`（Windows 一键脚本，自动拉起 MongoDB + 服务器，见第十一节）。

## 十、第八步：公网部署（让别人也能访问）

本机 `localhost:3000` 只有你自己能开。要让**任何人**通过链接访问，需要一条「公网隧道」。
提供两种方式，**推荐方式 B**。

### 方式 A：cloudflared（脚本内置，可先试）

项目 `tools/` 里已附带 `cloudflared.exe`（Windows）。在 cmd 里：

```bash
tools\cloudflared.exe tunnel --url http://localhost:3000
```

等待几秒，会打印一个 `https://xxxx.trycloudflare.com` 地址，发出去即可。

> ⚠️ 免费版 cloudflared 免费隧道经常断连，不一定稳定。如果不稳，用方式 B。

### 方式 B：localhost.run（SSH 隧道，推荐，更稳）

只要你有 `ssh` 命令（Windows 10+ 自带，或装 Git 自带）。在 cmd 里：

```bash
ssh -o StrictHostKeyChecking=no -o ServerAliveInterval=45 -o ServerAliveCountMax=3 -R 80:localhost:3000 nokey@localhost.run
```

几秒后打印：

```
https://af9baf2f813a89.lhr.life tunneled with tls termination
```

那个 `https://xxx.lhr.life` 就是你的**公网地址**，复制发给任何人，用手机/电脑都能打开。

**验证公网**：用手机（或浏览器无痕窗口）打开这个地址，能出现登录页即成功。

> ⚠️ 免费隧道限制：
> - 地址每 5~6 小时失效，失效后重新执行上面的命令，会得到**新地址**（旧地址作废）；
> - 隧道窗口/进程必须保持运行，关掉就断；
> - 想长期固定域名，可用 localhost.run 的付费自定义域名或云服务器 + Nginx。

## 十一、Windows 一键启动脚本（可选）

项目自带的 `start-chat.ps1` 会**自动完成**：启动 MongoDB → 启动服务器 → 启动隧道 → 打印地址。

```powershell
# 在项目目录里执行：
.\start-chat.ps1
```

> 注意：该脚本默认使用 cloudflared 隧道；如果 cloudflared 不稳，请改用方式 B 的 ssh 命令手动开隧道。

## 十二、常见问题排查

| 现象 | 原因与解决 |
|---|---|
| `npm start` 报 `ECONNREFUSED 27017` | MongoDB 没启动。先按第四节验证 `mongod` 在运行（或用脚本里的启动命令） |
| `EADDRINUSE` / 端口 3000 被占用 | 上一个 node 没关。cmd 里 `netstat -ano \| findstr :3000` 找到 PID，`taskkill /PID <PID> /F` 杀掉再启动 |
| 登录后界面 500「服务器内部错误」 | 大概率是旧版本 bug，确认你用的代码是最新版（v9+） |
| 帖子标签一直是「待分类」 | AI 未配置或 Key 无效。检查第七步 `ai.config.json` |
| 手机上主题/背景切换报错 | 确认服务器是最新版代码并已重启 |
| 中文乱码 | 用 UTF-8 编码保存文档/脚本；cmd 里执行 `chcp 65001` |
| 别人打不开公网地址 | 隧道已失效，重新执行第十节方式 B 拿新地址 |

## 十三、安全提醒（上线前必读）

1. **改掉默认密码**：管理员账号 `admin / admin123` 上线后立即「我的 → 修改密码」；
2. **保护 API Key**：`ai.config.json` 里的 Key 不要提交到 Git、不要发给别人；
3. **会话与隐私**：数据存在你的 MongoDB 里；若存敏感信息，建议把数据库也做备份；
4. **公网风险**：任何连上公网的服务都暴露给全网，请勿上传真实敏感资料用于演示，正式运营建议套一层 HTTPS + 鉴权（当前隧道已自带 TLS）。

## 十四、目录与数据说明

| 数据库集合 | 内容 |
|---|---|
| `users` | 用户账号（含头像/简介/主题/背景/标签） |
| `rooms` | 群房间与一对一私信会话 |
| `messages` | 聊天消息（阅后即焚的带 TTL 到期自动删除） |
| `posts` | 广场帖子（含评论、AI 标签与质量分） |
| `dm_invites` | 私信申请（待处理/已接受/已拒绝） |

数据默认存在 MongoDB 的数据目录（本指南为 `C:\mongodb\data_new`）。

---

## 十五、Linux / macOS 差异

- **Node.js**：用 `nvm` 安装，或官网下载对应系统安装包；
- **MongoDB**：用包管理器安装（如 Ubuntu `sudo apt install mongodb-org`），启动 `sudo systemctl start mongod`；
- **启动服务器**：同样 `npm start`；
- **一键脚本**：`start-chat.ps1` 是 Windows 专用，Linux/macOS 直接用 `npm start` + 第十节的隧道命令即可。
