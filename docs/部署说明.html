树洞 · 部署说明

从装环境到公网可访问，按顺序操作，每一步都能自己确认有没有做对

01技术栈

层技术作用
后端Node.js + Express处理登录、发帖、房间、资料等 HTTP 请求
实时通信Socket.IO房间 / 私信消息实时收发
数据库MongoDB存用户、帖子、房间、消息（阅后即焚靠数据库自动清理）
会话express-session登录状态保持
密码bcryptjs密码哈希加密
AI 能力火山方舟（豆包）API帖子打标 + 聊天回复建议（可选，不配也能用）
前端原生 HTML / CSS / JS无需构建，浏览器直接打开

请求链路大致是：浏览器 → 公网隧道 → Node.js（3000 端口）→ MongoDB（27017）/ AI 接口。

02环境要求

软件版本说明
Node.js≥ 18代码用到了内置 fetch、AbortController
MongoDB≥ 5.0（推荐 6 / 7）用官方 Community Server 版
系统Windows 10 / 11本文按 Windows 写，Linux / macOS 差异见文末
浏览器任意现代浏览器手机、电脑都能开

03安装 Node.js

  1. 打开 https://nodejs.org/zh-cn，下载 LTS（长期支持版）安装包；
  2. 双击安装，一路默认选项即可（安装路径可改，记住就行）；
  3. 按 Win + R 输入 cmd 回车，在命令行里输入：
node -v
npm -v

能打印出版本号（如 v20.x.x 和 10.x.x）就说明装好了。

04安装 MongoDB

  1. 打开 https://www.mongodb.com/try/download/community，Version 选最新稳定版，Platform 选 Windows，Package 选 msi；
  2. 双击安装：同意协议 → 选 Custom；安装路径建议改成 C:\mongodb（后面的脚本默认找这个路径）；
  3. 安装向导里如果有「Install MongoDB Compass」的勾选项，可以去掉（那是图形界面工具，不是必需的）；
  4. 装完一般会自动注册成 Windows 服务并开机自启，这一步依赖它；
  5. 打开 C:\mongodb，新建一个空文件夹，命名为 data_new；
  6. 验证：命令行里输入 mongod --version，能打印版本号即成功。
如果没自动注册成服务：可以手动启动，命令行运行 "C:\mongodb\bin\mongod.exe" --dbpath "C:\mongodb\data_new" --port 27017。这个窗口不能关，关了数据库就停了。

05获取代码

你会拿到一个项目源码压缩包。解压到任意目录，例如 D:\private-chat。解压后目录里应有这些关键文件：

private-chat/
├── server.js          # 后端服务器（入口）
├── ai.js              # AI 版主 + 智能回复
├── ai.config.json     # AI 接口配置（API Key 填这里）
├── package.json       # 依赖清单
├── seed-posts.js      # 初始化脚本（建管理员 + 预置帖子）
├── start-chat.ps1     # Windows 一键启动脚本（可选）
├── public/            # 前端页面
│   ├── index.html     # 登录 / 注册页
│   ├── chat.html      # 主界面（广场 / 房间 / 私信 / 我的）
│   ├── chat.js        # 前端逻辑
│   ├── style.css      # 全部样式
│   └── logo.svg       # 专属 LOGO
└── docs/              # 文档（本说明 + 产品使用说明）

06安装依赖

命令行进入项目目录：

cd D:\private-chat
npm install

看到 added xxx packages 即成功。国内网络慢的话，先执行 npm config set registry https://registry.npmmirror.com 换镜像再装。

07配置 AI（可选）

AI 功能（帖子自动打标签、聊天回复建议）依赖一个豆包 / 火山方舟的 API Key。暂时没有就跳过这步——网站其他功能都正常，只是帖子标签显示「待分类」、聊天里没有 AI 回复按钮。

打开 ai.config.json，改成：

{
  "apiKey": "ark-你的_API_Key",
  "model": "doubao-seed-2-1-turbo-260628"
}

Key 的获取：去 https://console.volcengine.com/ark 注册火山引擎账号，创建 API Key（形如 ark-xxxx-...）。模型名可以在这个文件里改，方舟平台上开通的豆包 / Seed 模型都行。

注意：如果配置文件里留着一个别人分享给你的真实 Key，务必换成你自己的，或删掉。这个 Key 等于你账户的钥匙，别提交到 Git 仓库，也别发给别人。

08初始化数据（可选但推荐）

首次运行前跑一次，会预置一个管理员账号和几条优质话题，让广场不至于空着：

node seed-posts.js

看到下面的提示就成功了：

✅ 管理员账号已创建: admin / admin123
🌱 已预置 6 条优质话题（作者: admin）
注意：这个脚本会清空广场现有帖子再写入种子数据，只在首次部署时跑一次，别重复运行。管理员初始密码是 admin123，上线后务必登录 admin 改成自己的密码。

09启动服务器

npm start

看到这两行说明启动成功：

✅ MongoDB 连接成功
服务已启动: http://localhost:3000

浏览器打开 http://localhost:3000，出现登录页即可。

这个命令行窗口要保持开着，服务器就在运行；关掉窗口服务就停了。Windows 下想后台运行，可以用 start-chat.ps1 一键脚本（见第 11 节）。

10部署到公网

本机的 localhost:3000 只有你自己能开。想让任何人通过链接访问，需要一条「公网隧道」。提供两种方式，推荐方式 B。

方式 A：cloudflared（脚本内置，可先试）

项目 tools/ 目录里带了 cloudflared.exe（Windows）。命令行执行：

tools\cloudflared.exe tunnel --url http://localhost:3000

等几秒会打印一个 https://xxxx.trycloudflare.com 地址，发出去即可。免费版 cloudflared 隧道不太稳定，如果一直断，用方式 B。

方式 B：localhost.run（SSH 隧道，推荐）

只要有 ssh 命令（Windows 10+ 自带，装 Git 也会带）。命令行执行：

ssh -o StrictHostKeyChecking=no -o ServerAliveInterval=45 -o ServerAliveCountMax=3 -R 80:localhost:3000 nokey@localhost.run

几秒后打印：

https://af9baf2f813a89.lhr.life tunneled with tls termination

那个 https://xxx.lhr.life 就是你的公网地址。复制发给任何人，手机 / 电脑都能打开。验证公网：用手机（或浏览器无痕窗口）打开这个地址，能出现登录页即成功。

免费隧道的限制：地址每 5~6 小时失效一次，失效后重新执行命令会得到新地址（旧地址作废）。隧道窗口必须保持运行，关掉就断。想要长期固定域名，用 localhost.run 的付费自定义域名，或买台云服务器配 Nginx。

11Windows 一键启动脚本（可选）

项目里的 start-chat.ps1 会自动完成：启动 MongoDB → 启动服务器 → 启动隧道 → 打印地址。

.\start-chat.ps1

这个脚本默认用 cloudflared 隧道；如果 cloudflared 不稳，改用第 10 节方式 B 的 ssh 命令手动开隧道。

12常见问题

现象原因与处理
启动报 ECONNREFUSED 27017MongoDB 没启动，按第 04 节确认 mongod 在运行
EADDRINUSE / 3000 端口被占用上一个 node 没关，命令行 netstat -ano | findstr :3000 找 PID，taskkill /PID <PID> /F 杀掉再启动
登录后 500「服务器内部错误」大概率是旧版本 bug，确认用的是最新版代码（v9+）
帖子标签一直是「待分类」AI 未配置或 Key 无效，检查第 07 节的 ai.config.json
手机上主题 / 背景切换报错确认服务器是最新版代码并已重启
中文乱码用 UTF-8 编码保存文件；命令行里先执行 chcp 65001
别人打不开公网地址隧道失效，重新执行第 10 节方式 B 拿新地址

13上线前的安全提醒

  1. 管理员账号 admin / admin123 上线后立即在「我的 → 修改密码」里改掉；
  2. ai.config.json 里的 Key 不要提交到 Git，不要发给别人；
  3. 数据都存在你的 MongoDB 里，如果担心丢失，给数据库做备份；
  4. 连上公网的服务就暴露给全网了，演示别传真实敏感资料；正式运营建议套一层 HTTPS + 鉴权（当前隧道已自带 TLS）。

14数据说明

数据库集合内容
users用户账号（含头像 / 简介 / 主题 / 背景 / 标签）
rooms群房间与一对一私信会话
messages聊天消息（阅后即焚的带 TTL 到期自动删除）
posts广场帖子（含评论、AI 标签与质量分）
dm_invites私信申请（待处理 / 已接受 / 已拒绝）

数据默认存在 MongoDB 的数据目录（本说明中为 C:\mongodb\data_new）。

15Linux / macOS 差异

  • Node.js：用 nvm 安装，或去官网下载对应系统安装包；
  • MongoDB：用包管理器安装（Ubuntu 例：sudo apt install mongodb-org），启动 sudo systemctl start mongod；
  • 启动：同样是 npm start；
  • 一键脚本：start-chat.ps1 是 Windows 专用，Linux / macOS 直接用 npm start + 第 10 节的隧道命令。
