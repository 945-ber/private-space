# 私密空间 · 产品使用手册

> 一个「可以随时关闭话题的论坛 + 一对一私密房间」的轻社交空间。
> 面向每一位普通用户：注册一个账号，就能进来发帖、聊天、交到真诚的朋友。

---

## 一、这是什么？

「私密空间」是一个**运行在公网、随时可以打开**的轻量社交网站。它把两件最需要的事放在了一起：

- **话题广场**：像论坛/贴吧一样，大家围绕一个话题发帖、回帖、讨论；
- **私密房间**：看对眼了，就开一个只有你俩（或你们几个人）的房间，实时私聊。

它不是一个"装在本机、只有自己能用"的程序，而是一个**任何人拿到链接就能访问**的网站——你的朋友、同好、陌生人，都能随时进来。

---

## 二、它比普通论坛/本地聊天室强在哪里？

| 对比项 | 普通本地论坛 / 聊天室 | 私密空间 |
|---|---|---|
| **能不能给外人用** | 大多只能本机或局域网用，别人打不开 | 部署在公网，发个链接任何人都能访问 |
| **内容质量** | 全靠人工，灌水、垃圾帖没人管 | 内置 **AI 版主**，自动给帖子打标签、筛质量、评深度 |
| **找想聊的人** | 论坛人海茫茫，无从下手 | 帖子带「深度分析 / 求助 / 情绪宣泄」等标签，按需直达 |
| **聊天质量** | 冷场、尬聊、不知道回什么 | 聊天时 **AI 生成 3 条回复建议**，点一下就发出 |
| **隐私** | 聊天记录永久躺着，删不掉 | 支持**阅后即焚**，到期自动物理删除 |
| **个性化** | 千篇一律 | 主题皮肤、自定义头像、主页封面、聊天背景，全都能改 |
| **维护** | 需要程序员手动清垃圾帖 | 管理员账号网页上一键删帖，无需碰代码 |

一句话：**普通论坛负责"让更多人说话"，私密空间负责"让每句话更值得被听"。**

## 三、快速上手（60 秒）

1. 打开别人分享给你的链接（形如 `https://xxxx.lhr.life`）；
2. 点「注册」，填一个用户名 + 密码（密码至少 6 位）；
3. 登录后，你会看到一个欢迎开场动画，然后进入**话题广场**；
4. 先在广场发一条帖、或回一条评论，感受一下；
5. 看到感兴趣的人，点进他的主页 → 「私信 TA」→ 申请私聊；
6. 或者自己建一个房间，把房间号发给朋友，一起实时聊天。

## 四、功能详解

### 1️⃣ 话题广场（论坛）

- **发帖**：点右上角「＋ 发帖」，填标题和内容，人人可发。
- **AI 版主自动打标**：你发出去之后，AI 版主会很快给帖子贴上标签——
  - `深度分析`：有干货、有逻辑、值得细读
  - `经验分享`：过来人的实践心得
  - `求助`：需要人帮忙/给建议
  - `情绪宣泄`：想被倾听的情绪话
  - `灌水` / `吐槽`：偏闲聊的内容
- **按需筛选**：广场上方有筛选条，你可以只看「深度分析」或「求助」，**精准找到你想看的东西**，不再被灌水淹没。
- **评论互动**：点进帖子就能看全文、写评论；帖子显示发布时间和互动数。
- **管理员维护**：管理员（账号 `admin`）可随时删除任何低质/违规帖子，保持广场干净。

### 2️⃣ 私密房间（实时聊天）

- **创建房间**：「我的房间」→「＋ 创建房间」，取个名字，得到一个**房间号**。
- **加入房间**：把房间号告诉朋友，朋友在「🔑 加入房间」输入房间号即可进入；也可以直接输入房间号回车加入。
- **实时聊天**：房间内消息实时送达（WebSocket），支持多条消息连续交流。
- **退出房间**：房间列表每条右侧有 ✕ 按钮，随时退出，不再霸占「我的房间」。
- **个性化聊天背景**：设置里可以给聊天区域换背景（4 款预设 / 上传自己的图片）。

### 3️⃣ 私信（一对一）

- 在话题广场看到想深聊的人 → 点进他的主页 →「私信 TA」→ 发出私聊申请；
- 对方在「私信」栏会看到待处理的申请，可**接受**或**拒绝**；
- 接受后你们就建立起一对一会话，可以继续深入交流。

### 4️⃣ 个人主页（你的名片）

- **封面背景**：头像后面那块大背景，可以换成 6 款渐变或你自己的图片，展示个性；
- **兴趣标签**：设置里填几个标签（如「夜谈、心理学、科技」），主页上以标签形式展示，方便别人找到同类；
- **个性签名**：一句话介绍自己；
- **在线状态**：头像旁有绿点/灰点，告诉别人你在不在线；
- **TA 的话题**：主页下方列出这个人发过的帖子，点击直达。

### 5️⃣ 个性化设置（「我的」页）

| 设置项 | 说明 |
|---|---|
| 个人资料 | 换头像（支持移除）、写简介、填兴趣标签 |
| 主题皮肤 | 4 套全局主题：海洋 / 暗夜 / 日落 / 星云，一键切换即时生效 |
| 聊天背景 | 聊天区域背景：4 款预设或上传图片，可恢复默认 |
| 主页背景 | 个人主页封面：6 款渐变或上传图片 |
| 修改密码 | 随时更换登录密码 |

### 6️⃣ AI 智能回复（告别冷场）

在私密房间或私信聊天时，输入框旁有一个 **AI 回复** 按钮：

- 点击后，AI 会**读取你们最近的聊天记录**，站在你的角度生成 **3 条候选回复**；
- 你觉得哪条合适，**点一下直接发送**；也可以先点选再自己改一改；
- 想聊但不知道说什么的时候，它会帮你想好下一句。

> 说明：AI 回复需要管理员在服务器上配置了 AI 接口才可用；未配置时该按钮自动隐藏，不影响其他功能。

### 7️⃣ 管理员专属

- 管理员账号 `admin` 登录后，广场每条帖子右上角会出现 ✕，**可删除任意帖子**（含他人）；
- 普通用户只能删除自己发的帖子；
- 建议管理员登录后第一时间「修改密码」改掉初始密码。

## 五、隐私与安全说明

- **密码加密存储**：密码使用 bcrypt 哈希保存，任何人都读不到明文。
- **阅后即焚**：部分房间消息支持阅后即焚，到期自动**物理删除**，不留痕迹。
- **会话机制**：登录状态由服务器会话管理，退出即失效。
- **请勿泄露**：请勿在公开帖子里填写手机号、住址等真实隐私信息；私聊也要保持警惕。

## 六、常见问题（FAQ）

**Q：为什么别人打不开我的链接？**
A：免费公网隧道大约每 5~6 小时会失效，需要管理员刷新一下隧道拿新地址。管理员看到新地址后发给你即可。

**Q：我发帖后标签是「待分类」？**
A：AI 版主处理需要几秒钟，稍等刷新即可；如果服务器没配置 AI，帖子会一直显示待分类，但不影响讨论。

**Q：怎么改回默认的聊天背景/主页背景？**
A：设置对应项里有「恢复默认」按钮，点一下即可。

**Q：登录密码忘了怎么办？**
A：目前需要管理员在数据库里重置，联系你的站点管理员即可。
